# Prueba de nivelación – Matemáticas 7.º

Prueba interactiva de selección múltiple con única respuesta (20 preguntas) para la nivelación de matemáticas de grado séptimo.

## Temas (4 preguntas por tema)

1. Operaciones con fracciones
2. Propiedades de la potencia en fracciones
3. Teorema de Pitágoras
4. Ecuaciones con fracciones
5. Regla de tres simple y compuesta

## Características

- Registro de nombre y curso del estudiante.
- Cronómetro de 40 minutos; la prueba se entrega sola al acabarse el tiempo.
- Las opciones A–D se reordenan en cada intento para dificultar la copia.
- Si se recarga la página, se conservan las respuestas.
- Resultados con nota en escala 1.0–5.0 (aprueba con 3.0), desempeño por tema y revisión con el procedimiento de cada pregunta.
- Descarga de resultados en .csv e impresión / guardado en PDF.

## Uso

Abre `index.html` en cualquier navegador (no requiere internet) o, con GitHub Pages activado, usa el enlace del sitio.

## Configuración

Al inicio del código JavaScript de `index.html` está el objeto `CONFIG`, donde se puede cambiar el nombre de la institución, el tiempo, la nota de aprobación y si se barajan las opciones o las preguntas.
